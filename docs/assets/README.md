# Assets De Documentacion

Esta carpeta contiene recursos livianos para README y documentos tecnicos.

## Screenshots

Ruta: `docs/assets/screenshots/`

Los screenshots deben ser PNG livianos, sin datos sensibles y preferiblemente
menores de 2 MB por archivo. No subir videos ni capturas gigantes. Si aparece una
ruta local de usuario o datos privados, repetir la captura con la zona oculta.

## Diagramas

Ruta: `docs/assets/diagrams/`

Los diagramas principales se guardan como Markdown/Mermaid para que sean
versionables y revisables sin herramientas externas.

## Uso

Los assets apoyan la comprension del sistema KX134 dual, pero la documentacion no
debe depender de screenshots para explicar el flujo operativo. Si los screenshots
estan pendientes, el repositorio sigue siendo auditable por README, diagramas y
reportes.
